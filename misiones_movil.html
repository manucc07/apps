📝 Editar lista de misiones —

Una misión por línea. Puedes editar, borrar o añadir misiones aquí. Para crear una partida debe haber al menos tantas misiones como jugadores; se elegirán sin repetir.

Los cambios solo afectan a las partidas nuevas que crees desde este móvil.
Esta app no usa servidor. El código comparte participantes y misiones, pero Base64 no las cifra: está pensado para un juego informal, no para mantener secretos frente a alguien que inspeccione el código.

¿Se acabó el tiempo?

Cuando estéis listos para resolver, revelad las misiones y comparadlas con lo que cada persona escribió. La aplicación no juzga si la respuesta es correcta: lo decidís vosotros.

Las notas se guardan solo en este dispositivo y no se sincronizan con el resto. Para lanzar cosas, utilizad únicamente objetos blandos y nunca apuntéis a la cara. La misión de Atenea se hace solo si sus padres están de acuerdo y ella está cómoda.
